# 学习笔记库

这是一个按主题沉淀学习内容的笔记仓库，目标是：

- 快速记录
- 持续整理
- 方便回顾

## 目录结构

```text
.
├── 00-索引.md
├── README.md
├── assets/
├── notes/
│   ├── 01-编程/
│   ├── 02-工具/
│   └── 03-语言/
└── templates/
    └── note-template.md
```

## 使用方式

1. 先打开 [00-索引.md](/Users/xujinsong/VSCode/SynologyDrive/学习笔记/00-索引.md)，找到对应主题。
2. 新建笔记时，直接复制 [templates/note-template.md](/Users/xujinsong/VSCode/SynologyDrive/学习笔记/templates/note-template.md)。
3. 图片、截图、附件统一放到 `assets/`。
4. 每写完一篇笔记，在索引里补一条链接。

## 命名建议

- 主题目录：`01-编程`、`02-工具` 这种固定分类
- 笔记文件：`YYYY-MM-DD-主题.md` 或 `主题.md`
- 一篇笔记只解决一个问题，后续靠链接串起来

## 推荐记录内容

- 学到了什么
- 为什么重要
- 示例代码或操作步骤
- 易错点
- 后续要继续补什么
